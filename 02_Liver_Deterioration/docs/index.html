✓ Three Pipeline Fixes Applied (v2) — Results Improved

Fix 1 — ED Lab Time-Window
Replaced hadm_id IS NOT NULL filter with 12-hour pre-admission time-window join. Recovered 184 additional liver admissions. ICU AUC improved 0.778 → 0.789 (+0.011). Root cause of 16% admission gap.
Fix 2 — Error Handling
Replaced bare except blocks with typed handlers. YDBNodeEnd returns None (expected). YDBError logs and re-raises (real errors). Silent failures no longer mask pipeline failures.
Fix 3 — Safe Delimiter
Replaced ^ field separator with \x1F (ASCII Unit Separator). Prevents field-shift when diagnosis titles contain carets. Critical for LLM context assembly accuracy.
